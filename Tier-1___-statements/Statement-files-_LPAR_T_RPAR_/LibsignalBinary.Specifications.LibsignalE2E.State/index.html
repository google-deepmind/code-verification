def spqrOffBL36–44 ↗#

SPQR switched off at PQ = Bytes: initial state [], send returns the unchanged empty state, no salt and an empty message for any coins, and recv is what the in-image spqr::recv does on the empty state (LibsignalSpqr.spqrRecvEmpty): [] and no salt if the message's preamble parses (msg_preamble), else Err(MsgDecode) (DEV-LS24). spqrOff (PQ = Unit, Computational/Proofs/SignalWireRoundTrip.lean) is the same except that its recv accepts every message.

def spqrOffB : Spqr Bytes Unit := ⟨fun _ _ => [], fun _ _ => some ([], none, []), fun _ msg => LibsignalSpqr.spqrRecvEmpty msg, fun _ _ => false, fun _ _ => false⟩

def ofGhostL59–62 ↗#

The epoch bookkeeping of a session-model state: its epoch counter, and its receiver chains' ratchet keys paired with their epochs.

def ofGhost {PQ : Type} (g : GhostState PQ) : EpochGhost := ⟨g.epoch, (g.session.receiverChains.map (·.senderRatchetKey)).zip g.chainEpochs⟩

def sendL64–67 ↗#

After a successful send by P (ACD19 Fig. 2 ep-mgmt): the epoch moves to P's next sending epoch if it is in a receiving one (as the session model's Params.send).

def send (P : Party) (e : EpochGhost) : EpochGhost := { e with epoch := if P.sendsIn e.epoch then e.epoch else e.epoch + 1 }

def recvL69–79 ↗#

After a successful receive of a message with ratchet key rk: the epoch t of the chain used and the new bookkeeping. A known key keeps everything; an unknown key starts epoch epoch + 1, which becomes the party's epoch, and its chain is appended (libsignal then keeps the last maxReceiverChains chains, session.rs add_receiver_chain), as the session model's Params.receive. ACD19 §5.2 "Epoch indexing": Signal names epochs by ratchet keys (DEV-LS8).

def recv (e : EpochGhost) (rk : PublicKey) : ℕ × EpochGhost := match e.chains.find? (·.1 == rk) with | some (_, t) => (t, e) | none => let cs := e.chains ++ [(rk, e.epoch + 1)] (e.epoch + 1, ⟨e.epoch + 1, cs.drop (cs.length - maxReceiverChains)⟩)
end EpochGhost

structure BinStateL83–97 ↗#

A party's state in the binary scheme: the party, its serialized session record (the bytes the binary returned), and its epoch bookkeeping.

DEV-M12 (formalization): the state carries bookkeeping the binary does not hold. ACD19 Fig. 8 keeps an explicit epoch counter t_cur in the state. The binary's record has none: Signal names epochs by ratchet keys (ACD19 §5.2). Lean adds the party and the epochs next to the record bytes; corr also leaks them. Effect: none: they are public bookkeeping.

structure BinState where /-- Which party (fixes the epoch parity and the binary's `who`). -/ party : Party /-- The serialized `SessionRecord` (opaque). -/ bytes : Bytes /-- The epoch bookkeeping. -/ epochs : EpochGhost deriving DecidableEq

def encChainKeyL120–122 ↗#

Chain.ChainKey { uint32 index = 1; bytes key = 2; } (the key's 32 little-endian bytes).

def encChainKey (ck : ChainKey) : Bytes := uint32Field 1 ck.index ++ bytesField 2 (HMAC.keyToBytes32 ck.key)

def encMessageKeyL124–126 ↗#

Chain.MessageKey in its Seed form (the only form the session model has): index = 1, seed = 5.

def encMessageKey (mk : MessageKeyGenerator) : Bytes := uint32Field 1 mk.counter ++ bytesField 5 mk.seed

def encSenderChainL128–131 ↗#

Chain for the sending chain: public key, private key, chain key, no message keys.

def encSenderChain (c : SenderChain) : Bytes := bytesField 1 c.ratchetKey.publicKey.serialize ++ bytesField 2 c.ratchetKey.privateKey.bytes.toList ++ msgField 3 (some (encChainKey c.chainKey))

def encReceiverChainL133–136 ↗#

Chain for a receiving chain: public key, chain key, skipped message keys (oldest first).

def encReceiverChain (c : ReceiverChain) : Bytes := bytesField 1 c.senderRatchetKey.serialize ++ msgField 3 (c.chainKey.map encChainKey) ++ (c.messageKeys.map fun mk => lenField 4 (encMessageKey mk)).flatten

def placeholderBaseKeyL138–140 ↗#

The placeholder base key of Alice's pending pre-key in encodeRecord: the all-zero X25519 key, serialized 0x05 ‖ 0^32 (DEV-M9).

def placeholderBaseKey : PublicKey := ⟨List.Vector.replicate 32 0#8⟩

def encPlaceholderPendingPreKeyL142–145 ↗#

PendingPreKey { optional uint32 pre_key_id = 1; bytes base_key = 2; int32 signed_pre_key_id = 3; uint64 timestamp = 4; } at constant values: pre_key_id absent, signed_pre_key_id and timestamp 0 (omitted), so only base_key.

def encPlaceholderPendingPreKey : Bytes := bytesField 2 placeholderBaseKey.serialize

def encSessionStructureSeedL147–158 ↗#

SessionStructure of a session-model state, fields in tag order 1–7, 9, 15 (10, 11, 13, 14 are the omitted defaults: registration ids 0, empty alice_base_key, no Kyber pre-key).

def encSessionStructureSeed (st : SessionState Bytes) : Bytes := uint32Field 1 st.sessionVersion ++ bytesField 2 st.localIdentity.serialize ++ bytesField 3 ((st.remoteIdentity.map IdentityKey.serialize).getD []) ++ bytesField 4 (HMAC.keyToBytes32 st.rootKey) ++ uint32Field 5 st.previousCounter ++ msgField 6 (st.senderChain.map encSenderChain) ++ (st.receiverChains.map fun c => lenField 7 (encReceiverChain c)).flatten ++ msgField 9 (if st.pendingPreKey then some encPlaceholderPendingPreKey else none) ++ bytesField 15 st.pqRatchetState

def encodeRecordL160–163 ↗#

SessionRecord::serialize of a session-model state: RecordStructure { current_session = 1; } (no previous sessions).

def encodeRecord (g : GhostState Bytes) : Bytes := msgField 1 (some (encSessionStructureSeed g.session))

def binStateOfL167–184 ↗#

binStateOf: the binary state of a session-model state: the same party, encodeRecord, the epoch bookkeeping. Used for the CLI scheme's initial states (cliScheme) and to relabel adversaries (Adversary.relabel).

def binStateOf (g : GhostState Bytes) : BinState := ⟨g.party, encodeRecord g, EpochGhost.ofGhost g⟩

def shortCiphertextL173–181 ↗#

shortCiphertext: the injections the CLI games admit: shorter than 2^32 bytes (cliPqLenOk, Computational/Specifications/Game/StatementPq.lean). The relabelled adversary answers the others none, as the games do.

DEV-M1 (machine model): inputs of 2^32 bytes or more are refused. ACD19 Fig. 2 lets the adversary inject any ciphertext. Here the games refuse such injections, and the CLI specs say nothing about them. Why: the run model needs bounded lengths. Effect: restricts the adversary (no claim for injections of 4 GiB or more); honest ciphertexts are shorter.

def shortCiphertext (c : Bytes) : Bool := decide (c.length < 2 ^ 32)
