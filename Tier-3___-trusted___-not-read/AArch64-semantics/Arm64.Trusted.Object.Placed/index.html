Placed Libraries: Layout-Generic Relocatable Code

Models a library as relocatable object code and data before linking (Obj.CodeBlock, Obj.PlacedLib, Obj.MultiPlacedLib), byte-slice memory mapping (Obj.HoldsBytes), and the output of a static linker (ld.lld) placing code at base and resolving external and data symbols through ρ (Obj.Placement, Obj.PlacedLib.Placeable, Obj.CodeBlock.patched, Obj.PlacedLib.program, Obj.PlacedLib.patchedData). Covers AArch64 ADRP+ADD to NOP+ADR, GOT, and TLS linker relaxations (Placement.relax), branch-to-branch retargeting (Placement.b2b), and undefined weak references (Placement.undefWeak).

Model

A PlacedLib is one rigid text block (CodeBlock: the concatenated .text* input sections of the library's objects, in link order, with alignment padding) plus data objects (SymDataInfo: one per .rodata/.data/.bss input section or merged-section piece). A Placement chooses:

  • base: the text block's address (no page alignment is assumed);

  • ρ: the address of every symbol not defined in the block (data objects, extern functions);

  • relax: for each relaxable ADRP+ADD pair (by ADRP byte offset), whether the linker relaxed it;

  • b2b: for each branch whose target is a block B, whether the linker retargeted it to that B's target;

  • undefWeak: for each weak reference (CodeBlock.weakRefs), whether the linker left it undefined (direct branches to it then branch to the next instruction). Every code relocation (including branches inside the block) is applied by CodeBlock.patched with targets addSignedAddr (resolve sym) addend. Placeable collects the conditions under which a linker applies the relocations without overflow; a contract over PlacedLib.program assuming Placeable holds for every such link. Whether some real binary is such a link is a separate, checkable fact (Obj.PlacedLib.InElf).

Auditing

Soundness of a library theorem about a real binary rests only on PlacedLib.program, PlacedLib.fnAddr, PlacedLib.dataInit and PlacedLib.InElf (bytes and permissions in the ELF). The relocation, relaxation and branch-to-branch model (patchedWord, Placeable) only affects completeness: if it disagrees with what the linker emitted, InElf fails on the real bytes (or the theorem is harder to prove), but it cannot make a false claim about those bytes.

structure CodeBlockL198–215 ↗#

One library's text, as a rigid block of relocatable code:

  • code: the bytes of the library's .text* input sections, concatenated in link order with alignment padding, before relocation (relocated fields hold the assembler's values);

  • align: the alignment the linker gives the block (its largest input-section alignment);

  • symbols: the functions it defines and their byte offsets in code;

  • relocs: its code relocations (RelocEntry.off is a byte offset in code); a relocation whose symbol is in symbols targets base + off, any other symbol resolves through ρ;

  • externs: functions it calls but does not define;

  • weakRefs: the subset of externs that the objects reference as undefined STB_WEAK symbols (a linker may leave these undefined, see Placement.undefWeak).

structure CodeBlock where code : List (BitVec 8) align : Nat := 4 symbols : List (String × Nat) := [] relocs : List RelocEntry := [] externs : List String := [] weakRefs : List String := [] deriving Inhabited

structure PlacementL226–249 ↗#

Where a linker placed a library: text at base, every other symbol at ρ sym, which relaxable pairs/sites (by byte offset in the block) it relaxed, and which branches (by byte offset) it retargeted past a block B (branch-to-branch).

The symbol map ρ sym gives:

  • the symbol's virtual address for direct code/data relocations, relaxed GOT (GotToNopAdr / GotToAdrpAdd) sites, data objects (PlacedLib.data), and extern stubs;

  • the GOT-slot virtual address for unrelaxed GOT (adrGotPage / ld64GotLo12Nc) and unrelaxed initial-exec TLS (tlsieAdrGottprelPage21 / tlsieLd64GottprelLo12Nc) sites; and

  • the thread-pointer (TPIDR_EL0) offset for relaxed initial-exec TLS (TLSIE → MOVZ/MOVK), TLSDESC → TLSLE, and direct local-exec TLS (TLSLE) sites. undefWeak sym says the linker left the weak reference sym (one of the block's weakRefs) undefined: a direct call26/jump26 to it is then patched to branch to the next instruction (AAELF64 §5.7.11.2, as ld.lld -static does), while its GOT sites still load the GOT slot at ρ sym (which then holds 0). (Mixed relaxed+unrelaxed GOT accesses to the same symbol, GOT-loading a PlacedLib.data symbol, or a direct branch to a defined weak symbol that is also GOT-loaded unrelaxed, would require a separate GOT-slot map if ever needed.)

structure Placement where base : BitVec 64 ρ : String → BitVec 64 relax : Nat → Bool := fun _ => false b2b : Nat → Bool := fun _ => false undefWeak : String → Bool := fun _ => false

def patchedWordL365–391 ↗#

The relocated word at byte offset off under placement pl:

  • the ADRP of a relaxed ADRP+ADD pair becomes NOP, its ADD becomes ADR Xd, sym + addend;

  • a GOT pair (gotPairAt) or initial-exec TLS relocation (tlsieRelaxableAt) is relaxed according to pl.relax (GotToNopAdr, GotToAdrpAdd, or TlsIeToLe);

  • any other relocated word is patched by patchRelocWord at place = base + off, targeting place + 4 for a direct branch to an undefined weak reference (undefWeakBranch) and relocTarget (which applies branch-to-branch) otherwise;

  • unrelocated words are unchanged.

def patchedWord (blk : CodeBlock) (pl : Placement) (off : Nat) : BitVec 32 := let w := blk.wordAt off match blk.relocAt? off with | none => w | some r => let place := pl.base + BitVec.ofNat 64 off if blk.relaxedAt pl off then nopWord else if 4 ≤ off && blk.relaxedAt pl (off - 4) then adrWord (adrTemplate w) place (blk.target pl r) else if r.kind.isGotOrTlsIe && 4 ≤ off && (blk.gotPairAt (off - 4) && pl.relax (off - 4)) then adrWord (adrTemplate w) place (blk.target pl r) else if r.kind.isGotOrTlsIe && (blk.gotPairAt off || blk.tlsieRelaxableAt off || (4 ≤ off && blk.gotPairAt (off - 4))) && pl.relax off then patchGotOrTlsIeRelaxed w place (blk.target pl r) r.kind else patchRelocWord r.kind w place (if blk.undefWeakBranch pl r then place + 4 else blk.relocTarget pl off r)

def relocInRangeL398–427 ↗#

Range and alignment condition for relocation kind at byte offset off (place = base + off) targeting target in blk under placement pl:

  • for .adrGotPage: True when relaxed to NOP + ADR (gotPairAt off && pl.relax off), or AdrpInRange place target otherwise;

  • for .ld64GotLo12Nc: AdrInRange place target when relaxed to NOP + ADR (4 ≤ off && gotPairAt (off - 4) && pl.relax (off - 4)), True when relaxed to ADRP + ADD (4 ≤ off && gotPairAt (off - 4) && pl.relax off), or Lo12Aligned 3 target when unrelaxed;
