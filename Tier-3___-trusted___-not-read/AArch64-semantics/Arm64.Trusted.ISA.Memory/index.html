Conservative Permissions, Option Perm, & W^X

read*/write* ignore permissions; Arm64.execInst checks canRead/canWrite/canExec before every access and faults otherwise. Writes never alter permissions. A byte's permission in Memory is m.perm a : Option Perm:

  • none is unmapped (no VMA). Permissions are conservative (at most the real machine's): "unmapped" (none) means "not known to be accessible", not "guaranteed to fault", so proofs must avoid unmapped bytes without deriving facts from unmappedness.

  • some p is mapped ((m.perm a).mapped = (m.perm a).isSome = true) with Linux protection bits p : Perm (r, w, x). In particular, some Perm.protNone (some ⟨false, false, false⟩) is a mapped PROT_NONE page: reserved in the virtual address space (canMap = false, so mmap and brk never overlap it), inaccessible (canRead = canWrite = canExec = false), and not frozen (frozen = false).

  • Executable memory is never writable (canWrite requires w ∧ ¬x, W^X), ensuring loaded instructions remain immutable across execution.

structure MemoryL110–131 ↗#

Byte-addressable 64-bit virtual memory: a partial map from addresses to an optional permission (Option Perm) and a byte (BitVec 8). none is an untouched address (unmapped, byte 0).

Representation. Lean core and Std provide no proof-friendly partial map over the full 64-bit address space: Std.TreeMap / Std.HashMap are finite, computational structures whose reasoning principles are about insertion histories, not pointwise lookups. A total function into Option is the simplest faithful model and makes pointwise lemmas (read-over-write, permission-over-write) one-line case splits.

Interface. Clients use the derived accessors read8 (the byte, 0 if absent) and perm (Option Perm: none if unmapped, some p if mapped with protection p) together with the base lemmas of ProofLib.Invariant / ProofLib.CoreLemmas (read8_write8, perm_write8, perm_mapFresh, ...), never cells directly.

Writes to unmapped addresses. write8 stores some (m.perm a, v), so a raw write to an unmapped address (m.perm a = none) creates some (none, v) with permission none (unmapped), never some (some ⟨false, false, false⟩, v). This keeps read8_write8 and perm_write8 unconditional while reserving some ⟨false, false, false⟩ (some Perm.protNone) exclusively for mapped PROT_NONE pages.

def KeepsFrozenL365–372 ↗#

m' keeps every byte that is frozen in m: same contents, same permission, same lazyFree bit, and same anonymous-mapping bit (isAnon). Every Step does this (instructions only store to canWrite bytes; extern hooks must, see Step.extern), so code and read-only data stay loaded throughout execution.

def KeepsFrozen (m m' : Memory) : Prop := ∀ a, m.Frozen a → m'.read8 a = m.read8 a ∧ m'.perm a = m.perm a ∧ m'.isLazyFree a = m.isLazyFree a ∧ m'.isAnon a = m.isAnon a
