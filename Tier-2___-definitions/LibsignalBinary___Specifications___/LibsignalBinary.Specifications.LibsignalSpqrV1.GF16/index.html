SPQR V1: GF(2^16) arithmetic (src/encoding/gf.rs)

Trusted in part. The theorems of Computational/Theorems/ use every definition in this file except reduce.REDUCE_BYTES, which is checked by Lean (see Computational/docs/TRUSTED_BASE.md).

Unaccelerated software specification of $\mathrm{GF}(2^{16}) = \mathbb{F}_2[x]/(x^{16} + x^{12} + x^3 + x + 1)$ (POLY = 0x1100b, taken under TokenInit, DEV-SPQR1): GF16 (ZERO, ONE, new, add, sub, constSub, mul, constMul, divImpl, div, constDiv), byte-table reduction (reduceFromByte, REDUCE_BYTES, reduceByteEntry, polyReduce), carryless multiplication (polyMul), and paired/slice scaling (mul2U16, parallelMult). All GF16 operations are panic- and overflow-free on u16 inputs; division computes self * other^(2^16 - 2) so division by 0 returns 0.
