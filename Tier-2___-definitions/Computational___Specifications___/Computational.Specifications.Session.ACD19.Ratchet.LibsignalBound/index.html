Adversary types, cost budgets and costed reduction bundles for the libsignal session bound

Trusted in part. The theorems of Computational/Theorems/ use every definition in this file except saltPRFTerm, wireOtccaTerm, multiSlotAdv and pubToAD; the ones they use are part of what you must read to trust the result. Those four are checked by Lean. Refine.SimProg, chainPRGTerm, fsShortBound, fsCompBound, fig8ShortBound and their …With forms are in Computational/Proofs/SpecLemmas/Session/ACD19/Ratchet/LibsignalBound.lean, checked by Lean. See Computational/docs/TRUSTED_BASE.md.

This file defines the adversary types, the message-blanking map of ACD19 Lemma 18 (Alwen, Coretti, Dodis, ePrint 2018/1037), the per-slot advantage terms of the symmetric-ratchet FS-AEAD bound, the explicit syntactic step-cost budgets, and the ReductionDsl costed reduction bundles used by libsignal_session_sm_r1_proto.

Every reduction in the session and E2E bounds is represented as a first-order ReductionDsl.CostedReduction or ReductionDsl.TwoStageCostedReduction over atomicSig ℓ Pt (AtomicOps.lean, TargetCodecs.lean), where every base sort carries an explicit 32-byte block measure sz and multi-step chain iterations, skipped-key scans, and protobuf wire codecs are accounted at primitive granularity. GRedBounded and GTwoStageBounded enforce single-execution step-cost budgets (ratchetCostBudget, fsRatchetCostBudget, ratchetFsAdapterBudget), program size, target query counts, operator/sampler size-honesty, and run-local state and output bounds, while GRedCostByKind and GRed2CostByKind refine step-cost and target-query accounting when game queries are split by kind (online vs. offline random-oracle queries).

Because macForgeryProb ≥ 2⁻⁶⁴ (8-byte MAC tag) and each FS-AEAD instance pays 4 * macForgeryTerm C qd = 4 * q * macForgeryProb outside the fsSlotCount qR slot sum (summed across epoch/message guesses and doubled by the window/signed-pre-key authenticity term), the bound is meaningful only for moderately long sessions: the MAC-forgery term reaches 2⁻³² at q = 9459 / 7327 / 1986 / 151 queries for qep = 0 / 1 / 10 / q, and reaches 1 at q = 619925131 / 480191941 / 130210321 / 38967 (see DEV-LS31 in Computational/docs/DEVIATIONS.md).

def GRedBoundedL198–224 ↗#

Step-cost, program-size, target-query, operator/sampler size-honesty, and run-local output/state block-size bounds for a 1-stage CostedReduction at source query bound q, target query bound qOut, and step-cost budget costBudget. Size bounds are quantified per run via supportWhen (I.AnswerFits B) so interfaces with unbounded Bytes or .nat fields remain satisfiable.

def GRedBounded {S : ReductionDsl.Sig} {O : ReductionDsl.Ops S} {ι κ : Type} {T : OracleSpec ι} {I : ReductionDsl.Iface S T} {G : OracleSpec κ} {C : ReductionDsl.GameCodec S G} {rIn aIn aOut out : ReductionDsl.Ty S} (R : ReductionDsl.CostedReduction O I G C rIn aIn aOut out) (wTag : I.Tag → ℕ) (wSamp : I.smp.Samp → ℕ) (q qOut costBudget : ℕ) : Prop := R.totalCost q ≤ costBudget ∧ R.size ≤ ReductionDsl.reductionSizeBudget + 2 ^ 12 * ReductionDsl.bits costBudget ∧ R.totalQueries wTag wSamp q ≤ qOut ∧ CostedOpsSizeHonest O ∧ CostedSampSizeHonest I.smp ∧ ∀ (B : ℕ), (∀ v : aOut.denote, CostedFits B aOut v) → ∀ (A : aIn.denote → OracleComp (unifSpec + G) aOut.denote), (∀ a, (A a).IsQueryBoundP (fun t => t.isRight = true) q) → (∀ a, ReductionDsl.AllGameQueriesFit B C (A a)) → ∀ (x : rIn.denote), CostedFits B rIn x → let widthB := 2 * (costBudget + q + 1) * (B + 1) (∀ y ∈ ReductionDsl.supportWhen (I.AnswerFits B) (R.eval A x), CostedFits widthB out y) ∧ (∀ r0 ∈ ReductionDsl.supportWhen (I.AnswerFits B) (R.init.eval (.cons x .nil)), ∀ r1 ∈ ReductionDsl.supportWhen (I.AnswerFits B) ((simulateQ R.impl (A r0.1)).run r0.2), CostedFits widthB R.σ r1.2)
