Term Concretization

Maps symbolic DY.Bytes terms of the 12-theory composed model to concrete HwBytes (gamma), paired with each term's structural shape and non-opaque subterm memo (gamma'). Algebraic constructors evaluate as transparent nodes via ExternInterpretation; SPQR, KEM public keys, non-32-byte KEM shared secrets, and signatures evaluate via OpaqueSymbolSemantics as opaqueNodes with literal shapes litOf v. Kyber implicit rejection (RejKey) is evaluated as a transparent node (S.kemDecap (S.kemPk s.bytes) c.bytes) so KdfExtract memo entries distinguish implicit rejection from attacker-chosen byte literals.

def clampByte (i : Nat) (b : BitVec 8) : BitVec 8 := if i = 0 then b &&& 0xF8#8 else if i = 31 then (b &&& 0x7F#8) ||| 0x40#8 else b

def variantBytes (b : HwBytes) (v : Fin 4) : HwBytes := if b.length = 32 then let u := x25519UCoord b let u' := if v.val / 2 = 1 ∧ u + DY.X25519.p25519 < 2 ^ 255 then u + DY.X25519.p25519 else u leBytes 32 (if v.val % 2 = 1 then u' + 2 ^ 255 else u') else b
